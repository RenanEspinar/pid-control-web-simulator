# PID Control Web Simulator

## Overview

This project is an interactive web-based simulator for PID control applied to a biomedical vacuum pressure system.

It allows users to modify PID parameters and observe how the system response changes.

## Objective

To demonstrate how proportional, integral, and derivative control affect the behavior of a dynamic pressure system.

## Engineering Context

The simulated system is inspired by biomedical vacuum therapy applications, where controlled negative pressure must remain stable despite leakage and disturbances.
